🔑 Admin

Admin Guideएडमिन गाइडएडमिन मार्गदर्शिका

👤Managing Users & Permissionsउपयोगकर्ता और अनुमतियांवापरकर्ते आणि परवानग्या

  1. 1Go to Users tab → click + Add User. Enter email and temporary password.Users टैब पर जाएं → + Add User। ईमेल और अस्थायी पासवर्ड दर्ज करें।Users टॅब → + Add User. ईमेल आणि तात्पुरता पासवर्ड प्रविष्ट करा.
  2. 2Click 🔐 Permissions on the user card.उपयोगकर्ता कार्ड पर 🔐 Permissions पर क्लिक करें।वापरकर्त्याच्या कार्डवर 🔐 Permissions वर क्लिक करा.
  3. 3Use a Quick Preset (Issuer / QC / Sales / Store) to apply standard permissions in one click.Quick Preset (Issuer / QC / Sales / Store) एक क्लिक में मानक अनुमतियां सेट करें।Quick Preset (Issuer / QC / Sales / Store) एका क्लिकमध्ये मानक परवानग्या द्या.
  4. 4Fine-tune checkboxes if needed, then click ✓ Save Permissions.जरूरत हो तो चेकबॉक्स बदलें फिर ✓ Save Permissions पर क्लिक करें।आवश्यक असल्यास चेकबॉक्स बदला नंतर ✓ Save Permissions वर क्लिक करा.

✅Assigning Tasks (Admin only)कार्य सौंपना (केवल एडमिन)काम सोपवणे (फक्त एडमिन)

⚠️
Admin only! Only Admin can assign tasks to users.केवल एडमिन! केवल एडमिन ही कार्य सौंप सकते हैं।फक्त एडमिन! फक्त एडमिनच काम सोपवू शकतो.
  1. 1Tasks tab → + Assign Task. Enter title, select user from Assign To.Tasks टैब → + Assign Task। शीर्षक दर्ज करें, Assign To से उपयोगकर्ता चुनें।Tasks टॅब → + Assign Task. शीर्षक द्या, Assign To मधून वापरकर्ता निवडा.
  2. 2Category: General for routine work, R&D for formula tasks (shows formula editor).Category: सामान्य काम के लिए General, फॉर्मूला के लिए R&D (फॉर्मूला एडिटर दिखेगा)।Category: सामान्य कामासाठी General, फॉर्म्युलासाठी R&D (फॉर्म्युला एडिटर दिसेल).
  3. 3Set Due Date & Priority → click ✓ Assign Task. User gets instant notification.Due Date और Priority सेट करें → ✓ Assign Task। उपयोगकर्ता को तुरंत नोटिफिकेशन।Due Date आणि Priority सेट करा → ✓ Assign Task. वापरकर्त्याला तत्काळ सूचना.

📦Issuing a Batchबैच जारी करनाबॅच जारी करणे

  1. 1Batches → + Issue Batch → select Product/BOM.Batches → + Issue Batch → Product/BOM चुनें।Batches → + Issue Batch → Product/BOM निवडा.
  2. 2Set Batch Size and Issue Date. The Issue Date determines the Financial Year.Batch Size और Issue Date सेट करें। Issue Date से वित्तीय वर्ष तय होता है।Batch Size आणि Issue Date सेट करा. Issue Date वरून आर्थिक वर्ष ठरते.
  3. 3Click Issue Batch. Number auto-assigned. Production sheet opens for printing.Issue Batch पर क्लिक करें। बैच नंबर स्वचालित। प्रोडक्शन शीट प्रिंट के लिए खुलती है।Issue Batch वर क्लिक करा. नंबर आपोआप. प्रोडक्शन शीट प्रिंटसाठी उघडते.
💡
Financial Year (FY):वित्तीय वर्ष:आर्थिक वर्ष: April 1 – March 31. A batch dated March 15 goes to FY 24-25, not FY 25-26.1 अप्रैल – 31 मार्च। 15 मार्च का बैच FY 24-25 में जाएगा।1 एप्रिल – 31 मार्च. 15 मार्चचा बॅच FY 24-25 मध्ये जाईल.

📁Year-End Archiveवर्ष-अंत आर्काइववर्ष-अंत आर्काइव्ह

  1. 1Settings → FY Archive → select completed FY.Settings → FY Archive → पूर्ण वर्ष चुनें।Settings → FY Archive → पूर्ण वर्ष निवडा.
  2. 2Click 📥 Download Archive (Excel) first — exports all data as separate sheets.पहले 📥 Download Archive (Excel) पर क्लिक करें।आधी 📥 Download Archive (Excel) वर क्लिक करा.
  3. 3After verifying the download, click 🗑 Delete FY Data. R&D Projects are never deleted.डाउनलोड सत्यापित करने के बाद 🗑 Delete FY Data। R&D Projects कभी नहीं हटाए जाते।डाउनलोड सत्यापित केल्यावर 🗑 Delete FY Data. R&D Projects कधीही हटवले जात नाहीत.
⚠️
Always download first. Deletion is permanent.पहले हमेशा डाउनलोड करें। हटाना स्थायी है।नेहमी आधी डाउनलोड करा. हटवणे कायमस्वरूपी आहे.

Issuer Guideइशूअर गाइडइश्यूअर मार्गदर्शिका

Issues batches, creates/edits BOM, views RM stock, records consumption.बैच जारी करना, BOM बनाना/संपादित करना, RM स्टॉक देखना, उपभोग दर्ज करना।बॅच जारी करणे, BOM तयार करणे/संपादित करणे, RM स्टॉक पाहणे, वापर नोंदवणे.

📦Issuing a New Batchनया बैच जारी करनानवीन बॅच जारी करणे

  1. 1Batches → + Issue Batch → select Product/BOM → set Batch Size & Issue Date.Batches → + Issue Batch → Product/BOM चुनें → Batch Size और Issue Date सेट करें।Batches → + Issue Batch → Product/BOM निवडा → Batch Size आणि Issue Date सेट करा.
  2. 2Click Issue Batch. The production sheet opens automatically — print it (Portrait A4).Issue Batch पर क्लिक करें। प्रोडक्शन शीट अपने आप खुलती है — प्रिंट करें।Issue Batch वर क्लिक करा. प्रोडक्शन शीट आपोआप उघडते — प्रिंट करा.
  3. 3To reprint: find the batch → click the 🖨 icon on the right of the row.पुनः प्रिंट: बैच ढूंढें → पंक्ति के दाईं ओर 🖨 आइकन पर क्लिक करें।पुन्हा प्रिंट: बॅच शोधा → ओळीच्या उजव्या बाजूला 🖨 चिन्हावर क्लिक करा.

📋Creating / Editing BOMBOM बनाना / संपादित करनाBOM तयार करणे / संपादित करणे

  1. 1BOM tab → + Create BOM → select Product & Category → set Base Batch Size.BOM टैब → + Create BOM → Product और Category चुनें → Base Batch Size सेट करें।BOM टॅब → + Create BOM → Product आणि Category निवडा → Base Batch Size सेट करा.
  2. 2Add Ingredients (name + qty). Use Process Step toggle for instruction rows like "Grind 3 Pass".सामग्री जोड़ें (नाम + मात्रा)। Process Step टॉगल से निर्देश पंक्तियां जोड़ें।साहित्य जोडा (नाव + प्रमाण). Process Step टॉगलने सूचना ओळी जोडा.
  3. 3QC Parameters: click ↓ Fill from Category Defaults → enter standard values per parameter.QC Parameters: ↓ Fill from Category Defaults पर क्लिक करें → प्रत्येक पैरामीटर का मानक मूल्य दर्ज करें।QC Parameters: ↓ Fill from Category Defaults वर क्लिक करा → प्रत्येक पॅरामीटरचे मानक मूल्य नोंदवा.
  4. 4Set Extra Additions (Dhoyela, Extra Output) and Pack Sizes. Click Save BOM.Extra Additions (ढोयेला, Extra Output) और Pack Sizes सेट करें। Save BOM पर क्लिक करें।Extra Additions (ढोयेला, Extra Output) आणि Pack Sizes सेट करा. Save BOM वर क्लिक करा.

🔜Recording RM ConsumptionRM उपभोग दर्ज करनाRM वापर नोंदवणे

  1. 1RM Stock → Record Consumption tab → set Date → select Category.RM Stock → Record Consumption टैब → तारीख सेट करें → Category चुनें।RM Stock → Record Consumption टॅब → तारीख सेट करा → Category निवडा.
  2. 2Type quantity used next to each material. Red border = exceeds available stock.प्रत्येक सामग्री के पास उपयोग की मात्रा दर्ज करें। लाल सीमा = उपलब्ध स्टॉक से अधिक।प्रत्येक साहित्याजवळ वापरलेले प्रमाण प्रविष्ट करा. लाल सीमा = उपलब्धतेपेक्षा जास्त.
  3. 3Click 📉 Save Consumption. Only rows with values entered are saved.📉 Save Consumption पर क्लिक करें। केवल भरी गई पंक्तियां सहेजी जाती हैं।📉 Save Consumption वर क्लिक करा. फक्त भरलेल्या ओळी सेव्ह होतात.
🔬 QC

QC GuideQC गाइडQC मार्गदर्शिका

Production details, QC test results, R&D projects, complaint responses.उत्पादन विवरण, QC परीक्षण, R&D परियोजनाएं, शिकायतों का जवाब।उत्पादन तपशील, QC चाचणी, R&D प्रकल्प, तक्रारींना उत्तर.

📝Entering Production Detailsउत्पादन विवरण दर्ज करनाउत्पादन तपशील नोंदवणे

  1. 1Batches → find batch with status "Issued" → click to open → click 📝 Production stage.Batches → 'Issued' स्थिति वाला बैच ढूंढें → खोलें → 📝 Production स्टेज।Batches → 'Issued' स्थितीचा बॅच शोधा → उघडा → 📝 Production स्टेज.
  2. 2Enter: Actual Qty Produced, Mill No, Charging Date, Filling Date → click Save Production.दर्ज करें: वास्तविक उत्पादित मात्रा, Mill No, Charging Date, Filling Date → Save Production।नोंदवा: प्रत्यक्ष उत्पादित प्रमाण, Mill No, तारखा → Save Production.

✅Entering QC Test ResultsQC परीक्षण परिणाम दर्ज करनाQC चाचणी परिणाम नोंदवणे

  1. 1Open batch → click 🔬 QC Testing. Parameters are pre-loaded from BOM.बैच खोलें → 🔬 QC Testing। BOM से पैरामीटर पहले से भरे होंगे।बॅच उघडा → 🔬 QC Testing. BOM मधून पॅरामीटर आधीच भरलेले असतील.
  2. 2Enter Actual Value for each parameter: Viscosity, Colour, SD/TF/HD Drying, Specific Gravity, Gloss etc.प्रत्येक पैरामीटर का वास्तविक मूल्य दर्ज करें: Viscosity, Colour, SD/TF/HD, Specific Gravity आदि।प्रत्येक पॅरामीटरचे प्रत्यक्ष मूल्य नोंदवा: Viscosity, Colour, SD/TF/HD, Specific Gravity इ.
  3. 3Select Overall Result: Pass / Fail / Conditional Pass → click Save QC.Overall Result चुनें: Pass / Fail / Conditional Pass → Save QC।Overall Result निवडा: Pass / Fail / Conditional Pass → Save QC.

🧪R&D ProjectsR&D परियोजनाएंR&D प्रकल्प

  1. 1R&D & QC tab → + New Project. Enter name, paint type, objective.R&D & QC टैब → + New Project। नाम, paint type, उद्देश दर्ज करें।R&D & QC टॅब → + New Project. नाव, paint type, उद्दिष्ट नोंदवा.
  2. 2Add Trials: + Add Trial → enter formula, test results, outcome (Pass / Approved as Final).Trials जोड़ें: + Add Trial → फॉर्मूला, परिणाम, outcome दर्ज करें।Trials जोडा: + Add Trial → फॉर्म्युला, परिणाम, outcome नोंदवा.
  3. 3When a trial is Approved as Final, the formula can be made into a BOM by the Issuer.जब trial Approved as Final हो, Issuer उसे BOM में बदल सकते हैं।Trial Approved as Final झाल्यावर Issuer त्याचा BOM बनवू शकतो.
💡
If Admin assigns an R&D task with a formula, it auto-creates an R&D project. Check R&D tab.अगर एडमिन R&D task फॉर्मूला के साथ सौंपें, तो R&D project अपने आप बनता है।एडमिनने R&D task फॉर्म्युलासह सोपवल्यास R&D project आपोआप तयार होतो.

⚠️Responding to Complaintsशिकायतों का जवाब देनातक्रारींना उत्तर देणे

  1. 1Complaints tab → find complaints with status "QC Pending".Complaints टैब → "QC Pending" स्थिति वाली शिकायतें।Complaints टॅब → "QC Pending" स्थितीच्या तक्रारी.
  2. 2Click complaint → + Add QC Response → enter Findings & Action Taken → set Status.शिकायत पर क्लिक करें → + Add QC Response → जांच और कार्रवाई दर्ज करें → Status सेट करें।तक्रारीवर क्लिक करा → + Add QC Response → तपासणी आणि कार्यवाही नोंदवा → Status सेट करा.

Glossary & Quick Referenceशब्दकोश और त्वरित संदर्भशब्दकोश आणि द्रुत संदर्भ

BOM
Bill of Materials — recipe/formula for a product with all ingredients and quantities.Bill of Materials — उत्पाद की रेसिपी/फॉर्मूला जिसमें सभी सामग्रियां और मात्राएं हों।Bill of Materials — उत्पादनाची कृती/फॉर्म्युला ज्यात सर्व साहित्ये आणि प्रमाणे असतात.
Batch Numberबैच नंबरबॅच नंबर
Auto-generated sequential number (e.g. 0027) within a Financial Year. Resets each April.वित्तीय वर्ष में स्वचालित क्रमांक (जैसे 0027)। हर अप्रैल से नई शुरुआत।आर्थिक वर्षात आपोआप क्रमांक (उदा. 0027). प्रत्येक एप्रिलला नव्याने सुरू.
Financial Year (FY)वित्तीय वर्षआर्थिक वर्ष
April 1 to March 31. Issue Date determines the FY of a batch.1 अप्रैल से 31 मार्च। Issue Date से बैच का वित्तीय वर्ष तय होता है।1 एप्रिल ते 31 मार्च. Issue Date वरून बॅचचे आर्थिक वर्ष ठरते.
Production Sheetप्रोडक्शन शीटप्रोडक्शन शीट
A4 printed form with ingredients, quantities, and QC parameters for a batch.A4 प्रिंट फॉर्म जिसमें सामग्रियां, मात्राएं और QC पैरामीटर हों।A4 प्रिंट फॉर्म ज्यात साहित्ये, प्रमाणे आणि QC पॅरामीटर असतात.
SD / TF / HD
Surface Dry / Touch Free / Hard Dry — three drying stages tested in QC.Surface Dry / Touch Free / Hard Dry — QC में परीक्षण किए जाने वाले तीन सुखाने के चरण।Surface Dry / Touch Free / Hard Dry — QC मध्ये तपासले जाणारे सुकण्याचे तीन टप्पे.
Reorder Levelपुनः-ऑर्डर स्तरपुनर्ऑर्डर पातळी
