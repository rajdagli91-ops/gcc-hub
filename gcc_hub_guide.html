👤 Managing Users & Permissions

  1. 1Go to the Users tab in the top navigation.
  2. 2Click + Add User. Enter the user's email and a temporary password. They will be prompted to change it on first login.
  3. 3Once created, click 🔐 Permissions on their card.
  4. 4Use a Quick Preset — 📦 Issuer, 🔬 QC, 💼 Sales, or 🏪 Store — to apply a standard permission set in one click.
  5. 5Fine-tune by checking or unchecking individual permission boxes, then click ✓ Save Permissions.
⚠️
Reset password: Click the 🔐 icon on a user card, then use the Reset Password section. The new password will auto-apply on the user's next login.

✅ Assigning Tasks

⚠️
Admin only! Only the Admin can create and assign tasks to users.
  1. 1Go to Tasks tab → click + Assign Task.
  2. 2Enter the Task Title and select the user from the Assign To dropdown.
  3. 3Select Category: General for routine work, or 🧪 R&D for formula-related tasks. Selecting R&D reveals a formula editor — fill formula name, type (Paint/Thinner/etc.) and ingredients.
  4. 4Set Due Date and Priority (High/Normal/Low). Click ✓ Assign Task.
  5. 5The user receives an instant 🔔 notification. R&D tasks with a formula also auto-create an entry in the R&D Projects tab.

📦 Issuing a Batch

  1. 1Go to Batches → click + Issue Batch.
  2. 2Select the Product / BOM. The ingredients list auto-loads from the BOM.
  3. 3Set the Batch Size (e.g. 1000 L) and confirm the Issue Date. The Issue Date determines the Financial Year.
  4. 4Click Issue Batch. Batch number auto-assigned (e.g. 0027) and the production sheet opens for printing.
💡
Financial Year: April 1 – March 31. A batch with Issue Date March 15 belongs to FY 24-25, not FY 25-26. Always confirm the date.

📁 Year-End Archive

  1. 1Go to Settings → FY Archive sub-tab. Select the completed Financial Year.
  2. 2Check the record counts shown (batches, complaints, R&D, RM consumption).
  3. 3Step 1: Click 📥 Download Archive (Excel) — exports everything as separate sheets.
  4. 4Step 2: After verifying the download, click 🗑 Delete FY Data. R&D Projects are never deleted.
⚠️
Always download the archive first. Deletion is permanent and cannot be undone.

📦 Issuing a New Batch

  1. 1Go to Batches → click + Issue Batch.
  2. 2Select the Product / BOM from the dropdown. Ingredients auto-scale to your batch size.
  3. 3Enter the Batch Size and confirm the Issue Date. Click Issue Batch.
  4. 4The production sheet opens automatically. Print it (Portrait, A4). The left 25mm margin is for filing/binding.

📋 Creating / Editing a BOM

  1. 1Go to BOM tab → click + Create BOM. Select Product and Category. Set the Base Batch Size.
  2. 2Add Ingredients: name + standard quantity. Toggle Process Step to insert instruction rows (e.g. "Grind 3 Pass").
  3. 3In QC Parameters: click ↓ Fill from Category Defaults then enter the standard values for this specific product.
  4. 4Set Extra Additions (Dhoyela, Extra Output rows) and Pack Sizes (0.2L, 0.5L, 1L etc.).
  5. 5Click Save BOM. Every save creates a numbered version — all previous versions are preserved.
💡
BOM Grouping: Click the 📁 Grouped button in the BOM toolbar to see all BOMs organised by category — much easier when you have many products.

🔜 Recording RM Consumption

  1. 1Go to RM Stock → Record Consumption sub-tab.
  2. 2Set the Date. Select a Category or leave as "All Categories" to see all materials.
  3. 3Type the quantity used next to each material. Remaining stock is shown in real time. Red = exceeds available stock.
  4. 4Click 📉 Save Consumption. Only rows with a value entered are saved.

🔬 Entering Production Details

  1. 1Go to Batches tab. Find the batch with status "Issued". Click on it to open.
  2. 2Click the 📝 Production stage. Enter Actual Qty Produced, Mill No, Charging Date, Filling Date.
  3. 3Click Save Production. Status updates to "In Production".

✅ Entering QC Test Results

  1. 1Open the batch → click 🔬 QC Testing stage. QC parameters are pre-loaded from the BOM.
  2. 2Enter the Actual Value for each parameter (Viscosity, Colour, SD/TF/HD Drying, Specific Gravity etc.).
  3. 3Select Overall Result: Pass / Fail / Conditional Pass.
  4. 4Click Save QC. A passed batch moves to "QC Passed" status.

🧪 R&D Projects

  1. 1Go to R&D & QC tab. See all ongoing projects. Click + New Project to create one.
  2. 2Inside a project, add Trials: click + Add Trial. Enter formula, test results, outcome (Pass / Approved as Final).
  3. 3When a trial is Approved as Final, the formula can be given to the Issuer to create a BOM.
💡
Formula via Tasks: If the Admin assigns an R&D task with a formula, it automatically creates an R&D project. Check R&D & QC for formulas received from Tasks.

⚠️ Responding to Complaints

  1. 1Go to Complaints tab. Complaints showing "QC Pending" need your response.
  2. 2Click on the complaint to open it. Click + Add QC Response.
  3. 3Enter your Findings and Action Taken. Set status to Resolved / Replacement Sent etc.

📦 Viewing Stock Levels

  1. 1Go to RM Stock → All Stock sub-tab.
  2. 2See all materials with current stock, unit, and reorder level. Click 📁 Grouped to see by category.
  3. 3Materials with ⚠️ Low Stock shown in red — inform the admin immediately for reordering.

📉 Recording Daily Consumption

  1. 1Go to RM Stock → Record Consumption sub-tab.
  2. 2Set today's Date. Use Filter by Category to narrow down (e.g. Pigments, Solvents, Resins).
  3. 3All materials in that category appear in a grid. Type the quantity used next to each material consumed today.
  4. 4System shows remaining stock live. Red border = you entered more than available — check and correct.
  5. 5Optionally add a Common Note (e.g. "Batch 0027") that applies to all entries.
  6. 6Click 📉 Save Consumption. The counter shows how many materials will be saved before you confirm.
💡
Tip: Click + Add All in any category header to pre-populate all materials at once, then just fill the ones you actually used.

✅ Completing Tasks

  1. 1Go to Tasks tab. Your tasks are in the 📋 Pending sub-tab.
  2. 2Click ✅ Mark Complete on a task. Add completion notes if any, then click Confirm Complete.
  3. 3The task moves to Completed tab with the date recorded. It auto-deletes after 60 days.

📚 Glossary

Glossary & Quick Reference

BOM — Bill of Materials
The formula/recipe for a product. Lists all ingredients and quantities for a given base batch size.
Batch Number
Auto-generated sequential number (e.g. 0027) within a Financial Year. Starts fresh from 0001 each April.
Financial Year (FY)
April 1 to March 31. The system uses the Issue Date to assign the correct FY to each batch.
Production Sheet
A4 printed form with ingredients, quantities, QC parameters, and space to record actual values during production.
QC Parameters
Test criteria for a product: Viscosity, Drying SD/TF/HD, Colour, Specific Gravity, Gloss etc. Set per category in Settings.
SD / TF / HD (Drying)
SD = Surface Dry, TF = Touch Free, HD = Hard Dry. Three stages of drying tested in QC.
R&D Project
A new formulation development project with multiple trials. Approved trials become BOM formulas.
RM Stock
Raw Material Stock. Tracks current quantities of all raw materials in the store.
Reorder Level
Minimum stock threshold. Below this level, the material shows a red ⚠ Low warning.
Extra Additions
Production sheet rows for Dhoyela, Extra Output, and other additions outside the main BOM formula.
FY Archive
Year-end process: exports data to Excel then deletes old FY records. R&D Projects are never deleted.
Task (R&D Category)
A task with a formula attached. When saved, the formula automatically creates an entry in R&D Projects.
