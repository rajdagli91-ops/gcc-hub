  2. 2Enter Original Pigment % (from the BOM, e.g. 15%). The Target Pigment % auto-fills to the same value. Change it only if you want a different final %.Original Pigment % (BOM से, जैसे 15%) दर्ज करें। Target Pigment % अपने आप भर जाता है। अलग Target चाहिए तो बदलें।Original Pigment % (BOM मधून, उदा. 15%) टाका। Target Pigment % आपोआप त्याच मूल्याने भरतो। वेगभो Target हवा ासल्यास बदला।
  3. 3In the Stainers Added table: enter name (optional), amount (L/kg), and pigment % for each stainer. Click + Add Stainer to add multiple.Stainers Added तालिका में: नाम, मात्रा (L/kg) आर pigment % दर्ज करें। अनेक स्टेनर जोज़ने के लिए + Add Stainer।Stainers Added तक्त्यात: नाव, प्रमाण (L/kg) आणि pigment % नोंदवा। अनेक stainers साठी + Add Stainer।
  4. 4Results show: Pigment% after stainer, Batch Size Increase (final − original), Final Batch Size (rounded down to 10L). The Action box says: "Increase from 1000L → 1160L (+160L total). Stainer already added: 50L · Still add: 110L base."रिजल्ट: Pigment% (स्टेनर के बाद), Batch Size Increase (अंतिम − मूल), Final Batch Size (10L तक क्रौࣾजण)।रिजल्ट: Pigment% (स्टेनर नंतर), Batch Size Increase (अंतिम − मूझ), Final Batch Size (10L ला जवउ floor)।

🔬Mode 2 — Actual Pigment% Measured (Reverse)मोड 2 — वास्तविक Pigment% मापा गयामोड 2 — प्रत्यर्ऱ Pigment% मोजला

  1. 1Select 🔬 Actual Pigment% mode. Enter Batch Size, Actual Measured Pigment%, and Target Pigment%.🔬 Actual Pigment% मोड चुनें। Batch Size, वास्तविक pigment% आर Target % दर्ज करें।🔬 Actual Pigment% मोड निवडा। Batch Size, प्रत्यर्ऱ मोजलेले pigment% आणि Target % टाका।
  2. 2System reverse-calculates exactly how much base to add to reach the target. Final batch size is rounded down to nearest 10L.सिस्टम स्वचालित बताता है कि फसल 10L तक धूल कृत आधारसे कितना बेस जोज़ना है।सिस्टम आपोआप जवझ बेस जोडायचे चू सांगते। Final batch 10L ला floor।

Still add: 110L base (stainer 50L already added).उदाहरण: 1000L बैच (15%) + 100L stainer (50%) → Final = 1160L। बड़ती = 160L। बेस जोज़ें: 110L।उदाहरण: 1000L ब़च (15%) + 100L stainer (50%) → Final = 1160L। वाड = 160L। Base जोडा: 110L।

BOM
Bill of Materials — formula/recipe for a product with all ingredients and quantities.उत्पादन की रेसीपी/फॉर्मुला।उत्पादनाची कृती/फॉर्म्युला।
Batch Numberबैच नंबरब़च नंबर
Auto-generated sequential number (e.g. 0027) per Financial Year. Resets every April.वित्तीय वर्ष में आंक (जैसे 0027)। हर अप्रैल ताजा होता है।आर्थिक वर्षात आंक (उदा. 0027)। प्रत्येक एप्रिलला रीसेट।
Financial Year (FY)वित्तीय वर्षआर्थिक वर्ष
April 1 to March 31. Issue Date determines batch FY.1 अप्रैल से 31 मार्च। Issue Date से FY तय होता है।1 एप्रिल ते 31 मार्च। Issue Date वरून FY ठरते।
SD / TF / HD
Surface Dry / Touch Free / Hard Dry — three drying stages in QC testing.चिकनास सुखाने के तीन चरण।सुकण्याचे तीन टप्पे।
Active Batchसक्रिय बैचसक्रिय ब़च

Stainerस्टेनरस्टेनर
A concentrated colorant added to base paint to achieve the target colour and pigment%.रंग आर pigment% पाने के लिए बेस पेंट में जोज़ा जाने वाला ज्यादा ारंगरंग आणि pigment% साठ्यासाठी बेस पेंटमध्ये मिसोझलेले सांद्ऱाचे रंजक द्रव्य
Old / Rejected Stockपुरा/रिजेक्टेड स्टॉकजुना/नाकारलेला स्टॉक
Old or rejected paint in stock. Prints in amber section on production sheet as reminder to use first.पुराना/रिजेक्टेड पेंट। प्रोडक्शन शीट में पहले उपयोग करने हेतु दिखता है।जुना/नाकारलेला पेंट। अाधी वापरहॊझला म्हणून प्रोडक्शन शीटवर दिसते।
